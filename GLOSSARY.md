# AutoCraft dashboard

The dashboard where people answer, watch and steer the triage pipeline for the storytold craft apps.

## Language

**Needs you**:
The page of work waiting on a person: the Decisions, Feedback and Stopped tabs.
_Avoid_: Inbox, To do

**Decision queue**:
The list of decisions on the Decisions tab, narrowed by a view and a scope.
_Avoid_: Inbox list

**View**:
Which decisions the queue shows by state: Waiting, Answered, Backlog, Snoozed or With opinions.
_Avoid_: Tab (the page tabs are Decisions, Feedback and Stopped)

**Scope**:
The filters that narrow a queue within a view: repos (one or several), kind, minimum waiting age and all questions.
_Avoid_: Filter set

**Project pick**:
The one repository a person chooses site-wide to narrow every list page; while it is set, a page's own repo scope is hidden and ignored.
_Avoid_: Scope, repo filter
